# InAmigos NGO Awareness Webpage 🌟

This project is a responsive NGO awareness webpage created using HTML and CSS for the InAmigos Foundation internship task.

## 🚀 Live Website

🔗 https://hetal22kar125.github.io/inamigos-awareness-webpage/

## 📌 Features

- NGO Introduction Section
- 6 Official NGO Projects
- Social Impact Section
- Volunteer Call-To-Action
- Responsive Modern Design
- Professional UI/UX

## 💻 Technologies Used

- HTML5
- CSS3

## 🌟 Projects Included

1. SEVA
2. BACHPANSHALA
3. JEEV
4. UDAAN
5. PRAKRITI
6. VIKAS

## 🎯 Objective

The objective of this project is to spread awareness about InAmigos Foundation initiatives and encourage people to participate in social impact activities.
